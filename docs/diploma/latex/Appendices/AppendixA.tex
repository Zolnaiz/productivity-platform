\chapter{Хэрэглэгчийн судалгааны асуулга}
\label{AppendixA}
Энэхүү асуулга нь ШУТИС-МХТС-ийн оюутан Б.Билгүүний ``Байгууллагын бүтээмжийг дэмжих платформ хөгжүүлэлт'' дипломын ажлын хүрээнд байгууллагын ажлын арга, хэрэгцээг судлах зорилготой. Асуулга нэргүй, 5 орчим минут үргэлжилнэ. Хариултыг зөвхөн нэгтгэсэн хэлбэрээр дипломын ажилд ашиглана.

\item \textbf{A2.} Таны албан тушаал

  \item Удирдлага
  \item Бусад
\end{itemize}
\item \textbf{A3.} Танай байгууллага 5S эсвэл lean аргачлал хэрэглэдэг үү?
\begin{itemize}[label=$\square$]

  \item Тийм, хэсэгчлэн
