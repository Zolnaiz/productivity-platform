### Дипломын тоог шинэчлэх дараалал
1. `cd backend && npm run results` → [RESULTS.md](RESULTS.md) (гараар засахгүй). Use-case-ийн тест түр санд ажиллахын тулд `DB_DATABASE=pp_uc`, хөтчийн тестийн тайланг оруулахын тулд `E2E_JSON=<playwright --reporter=json гаралт>` өгнө. Аль нэг suite ажиллах боломжгүй бол «давсан» биш, «ажиллаагүй» гэж бичигдэнэ.
2. `python docs/diploma/scripts/make_charts.py` → график.
3. 3-р бүлгийн хүснэгт, хураангуй, README-д ижил тоо.
4. LaTeX-ийг хөрвүүлж, `build_slides2.py`, `build_slides3.py`-аар илтгэлүүдийг дахин үүсгэнэ.
