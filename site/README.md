# BILZENO site

The public site for BILZENO's apps, published with GitHub Pages at
`https://bilzeno.github.io`. Plain HTML and one stylesheet: no build step.

| Page | Used for |
|---|---|
| `index.html` | The developer's home page (the Play Console website field) |
| `productivity/privacy.html` | The Play Store privacy policy URL for Бүтээмж |
| `productivity/delete-account.html` | The Play Store account deletion URL for Бүтээмж |

Before publishing, replace every `CONTACT_EMAIL` with the address people
should write to.

To publish: create the repository `BILZENO/bilzeno.github.io`, copy this
folder's contents to its root, and push; GitHub serves it within a minute.
A later app gets a folder of its own beside `productivity/`.
